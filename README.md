A tiny program that writes one short poem about agency — the power to choose and to act, passing between two agents when they agree on one plan — to `entry.txt`. The poem is fixed text carried inside the program, so every run produces the exact same output.

## Run it

```sh
node main.ts
```

This writes the poem to `/output/entry.txt`. To write it somewhere else, set `MAKEFUN_OUTPUT_DIR` first:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
